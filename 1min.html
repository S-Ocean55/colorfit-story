1계기0~10초

학교 축제에서 퍼스널컬러 '여름 쿨톤'을 받았는데, 정작 옷장 앞에선 뭘 입어야 할지 몰랐습니다. 그래서 진단 결과를 내 옷장과 오늘 코디까지 잇는 앱, ColorFit을 만들었습니다.

2만든 것10~24초

옷 사진을 넣으면 배경을 지우고 종류와 대표색을 자동으로 읽습니다. 그 색을 내 퍼스널컬러 팔레트와 비교해 어울림 점수를 내고, 오늘 날씨와 상황에 맞는 코디를 추천합니다.

3문제24~35초

외부 발표에서 "진단이 틀리면 추천도 무너진다"는 피드백을 받고 직접 재 보니, 같은 사진도 조명 색만 바꾸면 10번 중 4번은 다른 계절이 나왔습니다.

합성 조명 4종, 개발 338장, 기존 방식 39.87% · S3
4해결35~50초

조명은 얼굴 전체에 똑같이 걸리니까, 피부·머리·눈 색을 서로 비교하면 조명이 지워집니다. 이 특징으로 흔들림을 39.87%에서 11.91%로 줄였고, 코디 조합은 실제 코디 데이터로 학습해 진짜 코디를 가려내는 점수를 동전 수준 0.486에서 0.883으로 올렸습니다.

S3 · AUC C3·C5(Polyvore 고정 시험 1회)

진단 모델

FACER로 피부·머리·눈 분할 → Hybrid 12특징 → 다항 로지스틱 회귀(표준화·계절 균형 가중·온도 보정 T=0.9876, K11). 학습 사진마다 합성 조명 6장을 더해 9,142행, 규제 C=0.01은 사람 단위 5겹 교차검증의 Macro-F1로 선택딥 특징 모델은 교차검증 43.34%(F4a)로 색 특징 55.92%(D1)보다 낮았다

코디 모델

옷 사진 → FashionSigLIP 768(고정) → 두 옷 [a+b, |a−b|, a×b] → 2층 MLP → 같은 코디인지 맞히기(BCE). 오답은 같은 종류 다른 옷으로 한 벌 교체. 조기 종료 13 epoch다른 종류로 바꾸면 너무 쉬워 "어울림"을 못 배운다

평가

판정 뒤집힘(주 지표)조명만 바꿨을 때 판정이 달라진 비율같은 사람에게 같은 답을 주는지가 서비스 신뢰의 출발점
정확도 · Macro-F1계절마다 F1을 따로 내 평균흔한 계절만 맞혀 높아지는 착시 방지(Micro-F1은 정확도와 같은 값)
AUC · FITB(코디)진짜·가짜 코디 짝 비교 확률(무작위 0.5) · 빠진 옷 4지선다(찍기 25%)
